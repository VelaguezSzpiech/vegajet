## 2. Build

```sh
# CPU-only unit tests
cmake -S . -B build-cpu -G Ninja -DVEGAJET_CPU_ONLY=ON
cmake --build build-cpu && CI=1 ctest --test-dir build-cpu

# GPU build (ROCm 7.12; ROCm 7.14 fails the hsaco gate on two unmodified kernels)
cmake -S . -B build-gpu -G Ninja -DVEGAJET_CPU_ONLY=OFF -DVEGAJET_ROCM_PATH=<rocm-7.12-root>
cmake --build build-gpu -- -k 0 2>&1 | grep -cE 'gate PASS'   # expect every kernel PASS
```

`test_tokenizer_samplers` has a latency check that fails on a loaded machine.
Run it with `CI=1` (relaxed bound) or on an idle machine.
